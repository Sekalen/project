# Отчёт по финальному проекту

## Что я изучил на курсе:
- Spring Boot (Web, Security, Data JPA)
- PostgreSQL
- REST API
- Swagger (OpenAPI)
- Telegram Bot API
- Apache POI (Excel)
- Git и GitHub

## Как это можно применить в будущем:
Полученные навыки позволяют разрабатывать полноценные backend-приложения, включая безопасность, работу с файлами и интеграцию с внешними сервисами (Telegram).

## Источники, которые я использовал:
- Baeldung.com — Spring Security
- Документация Spring Boot
- GitHub

## Заключение:
Проект реализует все требования: CRUD, безопасность с ролями, логирование, загрузку файлов, отчёты, интеграцию с Telegram и схемы БД.
